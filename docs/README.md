# IdleTrigger docs

The repository is being rewritten from Go to Rust (see the banner in the
root README). Documentation from the Go implementation — user guides,
development notes, release-notes style, roadmap, and screenshots — was
removed from the working tree and remains available in the git history of
the last Go release.

New documentation for the Rust version lands here as features reach parity:
user guide, development guide, and release notes. The annotated
[configuration reference](../IdleTrigger.example.toml) stays at the
repository root and is shared by both implementations.
